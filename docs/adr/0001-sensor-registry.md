# 0001: sensor_taskのプラグインレジストリ化

- Status: 採用
- Date: 2026-09-14

## 背景

センサ追加のたびに `sensor_task.cpp` の改修が必要で、結合が強い。新機能を少しずつ乗せる方針と相性が悪い。

## 決定

- 汎用枠組み `Registry`（固定容量・ヒープ不使用）を `lib/` に置く。
- センサ毎のIF `ISensorPlugin`（`name`/`begin`/`update`）を定める。
- `begin` 失敗時はその1個だけ無効化し、他は継続する。
- 間引きはレジストリのdivider指定で行う（電圧60ms等）。
- 外部lib（`VoltageSensor`/`BMX055`）には薄い適合層（`VoltagePlugin`/`ImuPlugin`）を挟み、ピン等のボード固有値はコンストラクタ注入する。lib側はハードを知らない。
- 自動登録（staticコンストラクタ）は使わない。登録リストを明示する。
- 制御系パイプラインは核のため明示配線のままにし、枠組み化の対象外とする。

## 結果

- 追加・削除は適合クラス＋登録1行。`sensor_task.cpp` は40行程度に縮小。
- 代償：間接参照が増える。デバッグ時は登録リストを見ること。
