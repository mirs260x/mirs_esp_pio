# 0007: uplink発行の分周化（115200bps飽和によるWatchdog誤発火の回避）

- Status: 採用
- Date: 2026-10-05

## 背景

- 輸送路は115200bps半二重シリアル（約11.5KB/s）。`/odom` が毎周期15ms（約67Hz・約740B）で約49KB/s相当の発行要求となり、`/imu`＋`/mag` の毎周期発行再開で上りが飽和した。
- 上り飽和は下り `/cmd_vel`（10Hz）を圧迫し、1秒途絶でWatchdogが発火して直進テスト中に急停止→自動復帰を繰り返した。

## 決定

- `/odom`・`/imu`・`/mag` を15ms周期の4回に1回（約17Hz）に分周する。テレメトリ4種と同率。
- 分周器を `src/publishers/publish_divider.hpp`（rcl/Arduino非依存）に切り出し、3プラグインで共用してhost試験する。
- Watchdogの1000msは変えない（安全側の最終防衛として維持）。

## 結果

- 上り要求は約84KB/s相当から約24KB/s相当に削減し、下りに空きができる。`/odom` 17Hzは10Hz制御・EKF融合に十分。
- 代償：`/odom`・`/imu` の時間分解能が67Hzから17Hzに低下する。不足する用途が出たらbaudrate引き上げを別途検討する。
