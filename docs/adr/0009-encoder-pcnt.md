# 0009: エンコーダ計数のPCNT化

- Status: 採用
- Date: 2026-10-14
- Supersedes: [ADR 0005](0005-encoder-gpio-counting.md)

## 背景

- GPIO割込みによる両相計数は高回転時にCPU割込み負荷を増やす。
- AMT103-Vの2048PPR設定をX4計数し、8192カウント/回転として扱う。
- DiffDriveとOdometryCalculatorを統合し、エンコーダ読取から距離・オドメトリ更新までを単一IFにまとめる。

## 決定

- 左右エンコーダにESP32 PCNTユニットを1つずつ割り当て、A/B両相のエッジをX4計数する。
- PCNT新ドライバの累積機能で16-bitカウンタの折返しを吸収し、32-bit累積値は読み取り時に64-bitへ拡張する。
- PCNTフィルタを100 APBクロックtick（80MHz時約1.25us）に設定する。
- ホストテストではPCNT APIを実行できないため、同じ直交状態遷移を用いたシミュレーション実装でカウント・距離換算を検証する。
- 左右の取付方向補正、カウント差分、距離変換、オドメトリ積算を`OdometryCalculator`に集約し、`DiffDrive`は後方互換エイリアスとする。

## 結果

- Encoderあたりのカウント数を8192へ更新する。速度・オドメトリ計算およびROSへ送るカウント値はこの設定と整合させる。
- エンコーダ信号用のGPIO割込みを不要とし、PCNTユニットの他用途との競合に注意する。
- 実機の回転方向、カウント数、PCNTフィルタは書込み前または実機評価時に確認する。ホストテストはESP32 PCNTドライバ自体を検証しない。
