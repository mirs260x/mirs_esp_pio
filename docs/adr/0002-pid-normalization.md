# 0002: PIDのdt正規形化

- Status: 採用
- Date: 2026-09-14

## 背景

旧式（`I=Ki*Σerr`、`D=Kd*Δerr`、dt正規化なし）のゲイン `80/30/8` は100ms周期用に調整された値だった。15ms周期にそのまま持ち込むと積分が約6.7倍速く溜まり、全開時に前後振動（ハンチング）した。`COUNTS_PER_REV` 修正（4096→2048）で速度表示が2倍になったこともループをホットにした。

## 決定

- 正規形にする：`P=Kp*err`、`I=Ki*Σ(err*dt)`、`D=Kd*Δerr/dt`。ゲインは周期不変。
- `dt` は公称周期の1/3〜3倍にクランプする。公称はコンストラクタ注入（既定15ms）。
- `dt<=0` はP+保持Iのみ出力し、積分・微分を凍結する。
- 旧値からの換算目安：`Ti=Kp*dt/Ki_raw`、`Td=Kd_raw*dt/Kp`。
- 既定ゲインは等価換算＋CPR倍率補正で `Kp40/Ki150/Kd0.4` とする。
- MANUAL（プロポ）はPIDを通さず開ループ直結（`指令/MAX*255`）とする。ROS2のみPID閉ループ。

## 結果

- 周期変更時は公称だけ変えればゲイン再調整なし。
- 代償：旧ゲイン値との互換なし。流用時は換算が必須。
