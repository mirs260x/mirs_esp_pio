# プログラムの動作フロー詳細

## 📋 全体概要

このプログラムは**3つの並行実行パス**で動作します：

1. **ハードウェアタイマー割り込み** (15ms周期)
2. **メインループ (loop関数)** - 制御ループ実行
3. **micro-ROSコールバック** - 通信とパブリッシュ

---

└─────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────┐
    │ control_loop() 実行               │
    └──────────────────────────────────┘
         │
         ├─→ ① RC入力読取とモード更新
         │      ↓
         │   robot_ctrl.update()
         │      ├─ RC信号の有効性チェック
         │      ├─ モードスイッチ読取 (MANUAL ⇔ ROS2切替)
         │      ├─ MANUAL: RC左右スティック → 速度指令
         │      └─ ROS2: cmd_vel → 速度指令 (ウォッチドッグチェック)
         │
         ├─→ ② エンコーダーカウント取得
         │      ↓

         │
         ├─→ ⑤ ゼロ速度時のリセット
         │      ↓

         │       pid.reset();  ← 積分項・微分項クリア

         │

                ↓

         ↓

                        制御モード

┌─────────────────────────────────────────────────────────────────┐
│ MODE_MANUAL (手動モード)                                          │
└─────────────────────────────────────────────────────────────────┘

    RC Left Stick  → l_vel_cmd (左輪速度)
    RC Right Stick → r_vel_cmd (右輪速度)

    ・micro-ROS通信に依存しない
    ・左右独立制御
    ・即座に反応


┌─────────────────────────────────────────────────────────────────┐
│ MODE_ROS2 (自律モード)                                            │
└─────────────────────────────────────────────────────────────────┘

    /cmd_vel (linear_x, angular_z) → 差動駆動逆運動学
                                      ↓
    r_vel_cmd = linear_x + (wheel_base/2) × angular_z
    l_vel_cmd = linear_x - (wheel_base/2) × angular_z
    
    特徴:
    ・ウォッチドッグ付き (1秒タイムアウト)
    ・差動駆動ロボット標準制御
    ・ナビゲーションスタック対応


═══════════════════════════════════════════════════════════════════
                        周波数まとめ
═══════════════════════════════════════════════════════════════════

制御ループ:           66.67 Hz (15ms)
IMUパブリッシュ:      66.67 Hz (15ms)
テレメトリパブリッシュ: 16.67 Hz (60ms = 15ms × 4)
エンコーダー割り込み:  非同期 (車輪回転に依存)
RC信号:              50 Hz (20ms, RC受信機による)
micro-ROS spin:      最大 1000 Hz (1ms) ※実際はメッセージ到着次第


═══════════════════════════════════════════════════════════════════
                    micro-ROS停止時の動作
═══════════════════════════════════════════════════════────────════

micro-ROSが落ちた場合:

1. ハードウェアタイマー → 継続動作 ✅
2. loop() → 継続動作 ✅
3. control_loop() → 継続実行 ✅
4. RC入力 → 正常動作 ✅
5. モード切替 → 正常動作 ✅
6. モーター制御 → 正常動作 ✅

停止するのは:
- テレメトリ送信 ❌
- cmd_vel受信 ❌
- パラメータ更新 ❌

→ RCコントローラーで手動制御可能！（フェイルセーフ）
